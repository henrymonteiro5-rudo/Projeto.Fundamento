  Exchange de Criptomoedas

Projeto Universitário CCP110: Fundamentos de Algoritmos
Autores: Henry Monteiro e Mikael Escobar Rodrigues Souza

O projeto consiste no desenvolvimento, em Python, de uma exchange de criptomoedas simulada, que funciona como um “banco virtual” de ativos digitais. O sistema permite que usuários cadastrados gerenciem seus saldos em reais e em criptomoedas por meio de um ambiente de terminal interativo, reproduzindo o funcionamento das plataformas reais de negociação.
O objetivo principal é aplicar o material aprendido em aula e aproximar o contexto prático o mais possível da realidade. Os conceitos principais são estruturas de decisão, laços de repetição, manipulação de listas e dicionários, validação de entradas e organização modular do código.
